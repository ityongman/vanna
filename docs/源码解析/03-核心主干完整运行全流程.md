#### 步骤 1：用户发起 HTTP 请求

| 项目 | 内容 |
|------|------|
| **执行动作** | 用户通过浏览器/HTTP 客户端发送 POST 请求到 SSE 端点 |
| **入口函数** | `routes.py` 中的 `chat_sse()` 路由处理函数 |
| **入参** | `ChatRequest` JSON：`message`（自然语言问题）、`conversation_id`（可选）、`request_id`（可选）、`metadata`（可选） |
| **出参** | SSE 流：`text/event-stream`，每行 `data: {ChatStreamChunk JSON}\n\n` |
| **源码文件** | [servers/fastapi/routes.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/servers/fastapi/routes.py#L46-L85) |
| **数据流向** | `HTTP POST /api/vanna/v2/chat_sse` → `ChatRequest` → `ChatHandler` |

```python
# routes.py 核心代码
@router.post("/api/vanna/v2/chat_sse")
async def chat_sse(chat_request: ChatRequest, http_request: Request):
    # 从 HTTP Request 提取上下文
    chat_request.request_context = RequestContext(
        cookies=dict(http_request.cookies),
        headers=dict(http_request.headers),
        remote_addr=http_request.client.host,
        query_params=dict(http_request.query_params),
        metadata=chat_request.metadata,
    )
    return StreamingResponse(
        _stream_sse(chat_handler, chat_request),
        media_type="text/event-stream",
    )

async def _stream_sse(chat_handler, chat_request):
    async for chunk in chat_handler.handle_stream(chat_request):
        chunk_json = chunk.model_dump_json()
        yield f"data: {chunk_json}\n\n"
```

```python
async def handle_stream(self, request: ChatRequest):
    conversation_id = request.conversation_id or self._generate_conversation_id()
    request_id = request.request_id or str(uuid.uuid4())

    async for component in self.agent.send_message(
        request_context=request.request_context,
        message=request.message,
        conversation_id=conversation_id,
    ):
        yield ChatStreamChunk.from_component(component, conversation_id, request_id)
```

```python
# enhancer/default.py 核心代码
async def enhance_system_prompt(self, system_prompt, user_message, user):
    context = ToolContext(user=user, conversation_id="temp",
                          request_id=str(uuid.uuid4()), agent_memory=self.agent_memory)
    # 向量相似度检索
    memories = await self.agent_memory.search_text_memories(
        query=user_message, context=context, limit=5
    )
    if not memories:
        return system_prompt

    examples_section = "\n\n## Relevant Context from Memory\n\n"
    for result in memories:
        examples_section += f"• {result.memory.content}\n"
    return system_prompt + examples_section
```

#### 步骤 11：LLM 工具调用循环（核心循环）

这是整个系统的核心循环，最多执行 `max_tool_iterations`（默认 10）次。

| 项目 | 内容 |
|------|------|
| **执行动作** | Agent 进入 `while` 循环：调用 LLM → 解析响应 → 若含 ToolCall 则执行工具 → 将结果反馈 LLM → 继续循环 |
| **核心函数** | `Agent._send_message()` 中的 `while tool_iterations < self.config.max_tool_iterations:` 循环 |
| **源码文件** | [core/agent/agent.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/core/agent/agent.py#L400-L550)（近似位置） |

**完整循环流程：**

```
┌──────────────────────────────────────────────────────────────┐
│                   LLM 工具调用循环                            │
│                                                              │
│  ┌─────────────┐                                             │
│  │ 调用 LLM     │  _send_llm_request(request)                │
│  │             │  或 _handle_streaming_response(request)     │
│  └──────┬──────┘                                             │
│         │ LlmResponse                                        │
│         ▼                                                    │
│  ┌──────────────────────────────────┐                        │
│  │ 判断 response.is_tool_call()?    │                        │
│  └──────┬──────────────────┬────────┘                        │
│         │ YES              │ NO                              │
│         ▼                  ▼                                 │
│  ┌──────────────────┐  ┌──────────────────────┐              │
│  │ tool_iterations++ │  │ 返回最终文本回复      │              │
│  │ 逐工具执行        │  │ yield UiComponent    │              │
│  │ 结果追加到消息    │  │ break 退出循环       │              │
│  │ 重建 LlmRequest   │  └──────────────────────┘              │
│  │ 继续循环 ────────►│                                       │
│  └──────────────────┘                                        │
└──────────────────────────────────────────────────────────────┘
```

**典型 Tool Calling 交互序列（以 "Show Q4 sales" 为例）：**

```
第1轮 LLM 调用:
  system_prompt: "你是一个数据分析助手... 可用工具: run_sql, search_saved_correct_tool_uses..."
  user: "Show me Q4 sales by region"
  → LLM 决定调用 search_saved_correct_tool_uses
  → ToolCall(name="search_saved_correct_tool_uses", args={question: "Show Q4 sales by region"})

第1次工具执行:
  → SearchSavedCorrectToolUsesTool.execute()
  → AgentMemory.search_similar_usage()
  → 返回: "过去类似问题使用了 run_sql(sql='SELECT region, SUM(amount) FROM sales WHERE quarter='Q4' GROUP BY region')"

第2轮 LLM 调用:
  system_prompt: (同上)
  user: "Show me Q4 sales by region"
  assistant: [tool_call: search_saved_correct_tool_uses]
  tool: "过去类似问题使用了 run_sql(sql='SELECT region, SUM(amount) FROM sales...)"
  → LLM 决定调用 run_sql
  → ToolCall(name="run_sql", args={sql: "SELECT region, SUM(amount) AS total_sales FROM sales WHERE quarter='Q4' GROUP BY region ORDER BY total_sales DESC"})

第2次工具执行:
  → ToolRegistry.execute() → RunSqlTool.execute()
  → SqlRunner.run_sql() → 数据库执行
  → 返回: DataFrame(region, total_sales) + CSV 文本

第3轮 LLM 调用:
  system_prompt: (同上)
  ... (历史消息) ...
  tool: "region,total_sales\nNorth,150000\nSouth,120000\nEast,95000\nWest,80000"
  → LLM 决定调用 save_question_tool_args
  → ToolCall(name="save_question_tool_args", args={question: "Show Q4 sales by region", tool_name: "run_sql", ...})

第3次工具执行:
  → SaveQuestionToolArgsTool.execute()
  → AgentMemory.save_tool_usage()
  → 向量库持久化

第4轮 LLM 调用:
  → LLM 生成最终回复
  → "Here are the Q4 sales by region:\n\nNorth: $150,000\nSouth: $120,000\nEast: $95,000\nWest: $80,000"
  → response.is_tool_call() == False → break 退出循环
```

### 3.2 异常分支：错误处理与重试链路

Vanna 2.0 的异常处理使用 **Agent 工具循环 + LLM 自我纠错** 机制，而非传统的规则引擎重试。

#### 异常分支 1：SQL 执行报错

```
触发条件：数据库返回语法错误、表不存在、权限不足等异常
```

| 步骤 | 执行动作 | 源码文件 | 关键函数 |
|------|---------|---------|---------|
| 1 | `SqlRunner.run_sql()` 抛出异常（如 `psycopg2.errors.SyntaxError`） | [integrations/postgres/sql_runner.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/integrations/postgres/sql_runner.py#L65-L112) | `run_sql()` |
| 2 | `RunSqlTool.execute()` 捕获异常，返回 `ToolResult(success=False, result_for_llm="Error executing query: ...")` | [tools/run_sql.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/tools/run_sql.py#L155-L165) | `execute()` |
| 3 | `ToolRegistry.execute()` 将错误结果返回给 `Agent` | [core/registry.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/core/registry.py#L144-L278) | `execute()` |
| 4 | `Agent` 将错误消息追加到对话历史：`Message(role="tool", content="Error executing query: ...")` | [core/agent/agent.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/core/agent/agent.py#L520-L530) | `_send_message()` |
| 5 | Agent 重建 `LlmRequest`（含错误信息），再次调用 LLM | [core/agent/agent.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/core/agent/agent.py#L540-L550) | `_build_llm_request()` |
| 6 | LLM 分析错误原因，修正 SQL 并再次调用 `run_sql` | [core/agent/agent.py](file:///d:/workspace/sourceWorkspace/vanna/src/vanna/core/agent/agent.py#L400-L420) | 工具调用循环 |
| 7 | 若修正后成功 → 继续正常流程；若再次失败 → 进入下一轮循环（最多 10 次） | - | - |

```python
# RunSqlTool 中的异常捕获 - tools/run_sql.py 第155-165行
except Exception as e:
    error_message = f"Error executing query: {str(e)}"
    return ToolResult(
        success=False,
        result_for_llm=error_message,  # 错误信息直接传给 LLM
        ui_component=NotificationComponent(level="error", message=error_message),
        error=str(e),
    )
```

**典型案例：**

```
第1轮：LLM 生成 SQL "SELECT regon, SUM(amount) FROM sales"（拼写错误 regon）
  → run_sql 执行失败 → "Error executing query: column 'regon' does not exist"

第2轮：LLM 收到错误信息 → 分析修正
  → "The column 'regon' was misspelled. It should be 'region'."
  → 调用 run_sql(sql="SELECT region, SUM(amount) FROM sales GROUP BY region")
  → 执行成功
```

### 3.3 全局状态缓存逻辑

| 缓存对象 | 生命周期 | 存储位置 | 说明 |
|---------|---------|---------|------|
| `Conversation` | 整个会话期间 | `ConversationStore`（内存/文件系统） | 含完整消息历史，每次 `send_message` 追加新消息 |
| `User` | 单次请求 | `Agent._send_message()` 局部变量 | 每次请求重新解析，不跨请求缓存 |
| `ToolContext` | 单次请求 | `Agent._send_message()` 局部变量 | 含 `AgentMemory` 引用，供所有工具共享 |
| `system_prompt` | 单次请求 | `Agent._send_message()` 局部变量 | 每次请求重新构建（含 RAG 增强） |
| `LlmRequest` | 单次工具循环 | `Agent._send_message()` 局部变量 | 每次工具执行后重建（含新的工具结果消息） |
| `AgentMemory` 向量索引 | 全局持久化 | ChromaDB/FAISS/Pinecone 等 | 跨会话持久化，提供持续学习能力 |
| `ToolRegistry` 注册工具 | 全局 | `Agent.__init__()` 注入 | 应用启动时注册，运行期间不变 |
