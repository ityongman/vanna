# Vanna AI 源码深度解析文档

## 1. 项目基础总览

### 1.1 项目核心定位

Vanna AI 是一个开源的 **Text-to-SQL 智能代理框架**，核心目标是将自然语言问题自动转化为 SQL 查询语句并执行，最终以可视化图表和交互式表格的形式返回数据分析结果。

**版本现状：** 当前仓库为 **Vanna 2.0**（`pyproject.toml` 中 `version = "2.0.2"`），是对 Vanna 0.x 的完全重写。核心设计理念从原先的 "继承式混合类"（`VannaBase`）迁移到 **Agent 代理架构**，强调用户感知（User-Aware）、模块化扩展、流式响应和企业级安全。

**解决的业务痛点：**

- 非技术人员无需掌握 SQL 即可查询数据库，降低数据分析门槛
- 多租户 SaaS 场景下，用户身份贯穿全链路，支持行级安全（Row-Level Security）
- 内存学习机制：成功执行的 SQL 模式自动存入向量数据库，后续相似问题可复用（Few-shot 召回）
- 内置 Web 聊天组件，开箱即用，无需自行开发前端

**Text-to-SQL 实现方案：**

Vanna 2.0 并非传统的 "训练 schema → 向量检索 schema → LLM 生成 SQL" 模式，而是采用 **Agent + Tool Calling** 架构：

1. LLM 通过 Function Calling / Tool Use 机制，自主决定调用 `run_sql` 工具
2. 支持通过 `search_saved_correct_tool_uses` 工具从向量库中搜索历史成功 SQL 模式（代替传统 RAG schema 检索）
3. 支持通过 `save_question_tool_args` 工具将成功执行的 SQL 存入向量库，形成持续学习闭环
4. `LlmContextEnhancer` 在每次 LLM 调用前自动从 `AgentMemory` 检索相关文本记忆，增强系统提示词

### 1.4 版本基线、分支区别、核心设计思想

**版本基线：**

- 当前版本：**Vanna 2.0.2**（`pyproject.toml`）
- Python 最低版本：`>=3.9`
- 构建系统：`flit_core`

**Vanna 2.0 vs Vanna 0.x 核心区别：**

| 维度 | Vanna 0.x (legacy/) | Vanna 2.0 (当前) |
|------|---------------------|-------------------|
| 架构模式 | 多继承混合类 `VannaBase` | Agent 代理架构 `Agent` |
| 用户感知 | 无 | 全链路 User-Aware |
| LLM 调用 | 直接调用 `submit_prompt()` | Tool Calling / Function Calling |
| Schema 训练 | `train(ddl=...)`, `train(sql=...)` | AgentMemory 自动记忆 |
| 向量检索 | 直接检索 DDL/SQL | 检索历史 Tool 使用模式 |
| 前端 | 无内置 | 内置 `<vanna-chat>` Web Component |
| 响应方式 | 同步返回 DataFrame | 流式 SSE 返回 UI 组件 |
| 扩展性 | 继承修改 | 依赖注入 + 接口实现 |

**核心设计思想：**

1. **依赖注入（Dependency Injection）**：所有能力通过构造函数注入，而非继承。例如 `Agent` 需要 `LlmService`、`ToolRegistry`、`UserResolver`、`AgentMemory` 等，全部通过 `__init__` 注入。

2. **接口-实现分离**：`core/` 定义抽象接口（ABC），`integrations/` 提供具体实现。新增 LLM/数据库/向量库只需实现对应接口。

3. **Agent 工具调用模式**：LLM 不直接生成 SQL 文本，而是通过 Function Calling 调用 `run_sql` 工具。这避免了 SQL 解析的脆弱性，LLM 生成的 SQL 作为工具参数传入。

4. **持续学习闭环**：成功执行的工具调用模式自动存入向量库 → 后续相似问题通过 `search_saved_correct_tool_uses` 召回 → 形成 Few-shot 增强 → 提高 SQL 准确率。

5. **流式 UI 组件**：后端不返回纯文本，而是返回结构化的 `UiComponent`（DataFrameComponent、ChartComponent、StatusCard 等），前端 Web Component 直接渲染。

6. **用户感知**：`User` 对象贯穿全链路（`id`、`username`、`email`、`metadata`），审计日志（`AuditLogger`）基于用户身份记录工具调用与结果。
